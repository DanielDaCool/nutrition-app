# Nutrition App

Personal Android app for food logging, daily weigh-ins, adaptive calorie and macro targets,
and steps + workouts from Health Connect (Hevy writes workouts there).

- Plan: [docs/plan.md](docs/plan.md)
- Calorie engine: [docs/engine.md](docs/engine.md)
- Developer guide: [CLAUDE.md](CLAUDE.md)

## Install on your phone
Each CI run on `main` or a pull request uploads an APK artifact (`nutrition-app-apk`).
Download it from the run's Summary page, unzip, and open the `.apk` on the phone.
