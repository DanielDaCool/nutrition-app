# PC dashboard

Read-only. Nothing here is hosted — open `docs/index.html` directly in a
browser (double-click it, or `file:///path/to/nutrition-app/docs/index.html`).
It fetches your data straight from GitHub over HTTPS, so nothing needs a
server. GitHub Pages isn't used: Pages only serves a *private* repo's site
publicly on a paid plan, and this repo stays free and private.

First run asks for:
- A GitHub personal access token, `gist` scope only (github.com/settings/tokens).
- The gist id, shown in the phone app after Settings → PC dashboard → Sync now.

Both are stored only in that browser's `localStorage`.
